# فريق — HR System

نظام موارد بشرية بالعربي يعمل مباشرة في المتصفح، بواجهة متجاوبة للموبايل والكمبيوتر.

## التشغيل

افتح ملف `index.html` في متصفح حديث. احتفظ بملفي `app.js` و`styles.css` بجانبه.

لإنشاء ملف HTML واحد يحتوي البرنامج كاملًا، شغّل `npm run build` باستخدام Node.js؛ ستجده في `dist/HR-System.html`. يمكن تنزيله وفتحه في متصفحك الشخصي. بعض المتصفحات المُدارة تمنع فتح الملفات المحلية؛ استخدم خادم التطوير عندها.

للتطوير وتشغيله على عنوان محلي ثابت، تحتاج Python 3:

```sh
cd /workspace/MyTracker-
python3 -m http.server 8000 --bind 0.0.0.0
```

افتح المنفذ 8000 محليًا في متصفحك. لا يحتاج التطبيق إلى تثبيت حزم أو خطوة بناء للتشغيل.

## الوظائف

- لوحة ملخص محسوبة من سجلات الفريق، ومخطط للحضور خلال آخر سبعة أيام.
- إضافة الموظفين وعرض ملفاتهم وتعديلهم وحذفهم، والبحث والتصفية حسب القسم والحالة.
- تسجيل الحضور والتأخير والغياب والإجازات، وأوقات الحضور والانصراف لكل يوم.
- تسجيل طلبات الإجازة ومراجعتها بالموافقة أو الرفض، مع منع تداخل الطلبات.
- ملخص الرواتب الأساسية والأقسام وتصدير الموظفين والحضور بصيغة CSV.
- تغيير اسم الشركة ورمز العملة، وتنزيل نسخة احتياطية JSON واستعادتها.
- بيانات افتراضية للتجربة، وخيار البدء بسجلات فارغة من صفحة الإعدادات.

## أين تُحفظ البيانات؟

هذه نسخة محلية أولية، تُحفظ بياناتها في `localStorage` في متصفحك فقط. يستطيع أي زائر للرابط تجربة النظام، لكن سجلاته منفصلة عن سجلات بقية الزوار. لا توجد حسابات دخول أو قاعدة بيانات مشتركة أو مزامنة بين الأجهزة. تغيير عنوان الموقع أو المتصفح يعطي مساحة منفصلة. احتفظ بنسخة احتياطية قبل حذف بيانات المتصفح أو الانتقال إلى رابط آخر.

الملفات المنشورة تحتوي بيانات تجريبية فقط. بيانات الموظفين التي تدخلها لا تُرسل إلى GitHub أو إلى خادم. ملفات التصدير والنسخ الاحتياطية تحتوي بياناتك؛ احتفظ بها في مكان خاص.

هذه النسخة مناسبة للتجربة وإدارة سجلات محلية، وليست نظام موظفين مشتركًا جاهزًا للاستخدام المؤسسي. ذلك يحتاج مهمة لاحقة لإضافة خادم وقاعدة بيانات وتسجيل دخول وصلاحيات مناسبة.

## تفاصيل الحسابات

- إحصاءات الحضور تُحسب للموظفين النشطين فقط. «حاضر» و«متأخر» كلاهما يُحسبان في نسبة الحضور.
- السجل غير الموجود يظهر «لم يُسجّل»؛ لا يُحسب كغياب تلقائيًا.
- تواريخ اليوم تُحدد بتوقيت القاهرة. أوقات الدوام المدخلة هي أوقات الشركة ليوم واحد؛ النوبات التي تعبر منتصف الليل غير مدعومة حاليًا.
- أيام الإجازة أيام تقويمية شاملة البداية والنهاية. الموافقة على طلب إجازة لا تغيّر سجل الحضور تلقائيًا؛ تُسجل الإجازة في الحضور بشكل منفصل.
- الرواتب المعروضة أساسية شهرية للموظفين النشطين؛ لا تشمل الضرائب أو التأمينات أو البدلات أو الخصومات. تغيير رمز العملة لا يحوّل المبالغ.

## النشر على GitHub Pages

انشر ملفات المشروع على فرع `main` في المستودع، ثم من GitHub:

1. افتح **Settings → Pages**.
2. تحت **Build and deployment** اختر **Deploy from a branch**.
3. اختر فرع **main** ومجلد **/(root)** ثم **Save**.
4. بعد اكتمال النشر سيعرض GitHub رابط الموقع؛ استخدم الرابط الذي يظهر هناك.

لا توجد مفاتيح API أو أسرار مطلوبة لهذا التطبيق. اسم المستودع في الروابط حساس لحالة الأحرف. لا تحتاج GitHub Actions أو أدوات بناء.

## اختبارات المتصفح

تحتاج Node.js 20 أو أحدث وPython 3 ومتصفح Chromium. لا تتطلب هذه الأدوات لتشغيل ملف HTML مباشرة؛ هي لفحص المشروع أثناء التطوير.

```sh
npm ci
npm test
```

الاختبار يشغّل خادمًا مؤقتًا بنفسه ويغلقه عند الانتهاء. يستخدم Chromium من `/usr/bin/chromium`؛ عيّن `CHROMIUM_PATH` إذا كان متصفحك في مسار مختلف. يمكن استخدام `TEST_URL` لفحص خادم يعمل بالفعل. تغطي الفحوص إدارة الموظفين والتحقق من المدخلات والحضور والإجازات والتصدير والاستعادة واستمرار البيانات وعرض الموبايل. لا تختبر هذه الفحوص نظام دخول أو قاعدة بيانات؛ كلاهما غير موجود في هذه النسخة.

فحص فتح `file://` اختياري، ويُسجّل كتخطي إذا منعت سياسة إدارة المتصفح الملفات المحلية. فحوص التشغيل عبر HTTP والنسخة المستقلة تظل مطلوبة.
